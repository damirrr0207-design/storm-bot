# STORM BOT — STORM STUDIO

Статический сайт + Netlify Function для общения с OpenRouter.

## 1. GitHub
1. Создай репозиторий `storm-bot-site`.
2. Загрузи содержимое этой папки в корень репозитория. Файл `.env` сюда НЕ добавляй.
3. Не публикуй API-ключи в коде или сообщениях.

## 2. Netlify
1. Войди на https://app.netlify.com/
2. Добавь новый сайт, импортировав репозиторий GitHub `storm-bot-site`.
3. Build command оставь пустым; publish directory — `.`. `netlify.toml` задаёт эти параметры.
4. После первого развёртывания открой настройки сайта → Environment variables.
5. Создай `OPENROUTER_API_KEY` со значением своего ключа OpenRouter.
6. Не добавляй ключ в GitHub, `index.html`, `app.js` или публичные сообщения.
7. По желанию создай `OPENROUTER_MODEL` со slug модели, доступной твоему аккаунту, например `deepseek/deepseek-chat`. Бесплатность и доступность модели не гарантируются.
8. Запусти новое deploy после изменения переменных.

## 3. Проверка
Открой адрес Netlify, отправь сообщение в чате. Если есть ошибка, проверь логи Functions в Netlify и доступность модели в OpenRouter.

## Важно
- Секретный ключ хранится только в переменных окружения Netlify.
- Это стартовый прототип. Для публичного сайта позже добавь лимиты запросов/защиту от злоупотреблений.
- История диалогов хранится только в памяти открытой страницы браузера и не синхронизируется между устройствами.
- Бесплатные модели могут иметь квоты, задержки и меняться.
- Чтобы попасть в Яндекс Поиск, сначала опубликуй сайт, затем добавь его в Яндекс Вебмастер и подтверди права. Индексация не мгновенная и не гарантируется.
